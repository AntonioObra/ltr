# ltr

Last Trace CLI version

## Development

### Build

```go
go build -o ltr main.go
go build -o ~/bin/ltr .
```

### Run

```go
./ltr
```

### Config

```go
./ltr config set <key> <value>
```

### Init

To use this tool, you have to init it in the
desired project / directory / repository by running:

```go
ltr init
```

### Tasks

#### New Task

```go
ltr task new <task-name>
```
